# Minecraft-Shaders
A exploration of how Minecraft rendering pipeline works. This is a recreation of Acerola's Minecraft Shader purely for educational and learning purposes.

# Disclaimer
These are just shaders just for showcase and not meant to be played with. There are limitless possibilities to update this with other post processing effects. I also tried to implement distant horizons so if anyone trying is required to have distant horizon. Also its a very poor implementation of distant horizons.

# Effetcs
* Diffuse Lighting 
* Soft Shadows
* Contrast a function of view distance
* Bloom
* Fog (based on distance and height)
* ACES Tone mapping
